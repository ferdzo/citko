# Fixture provenance

`citko-evidence.epub` and `citko-evidence.pdf` are generated from scratch by
`generate.py`. The short story text and document structures are original and
dedicated to the public domain under CC0 1.0 Universal
(https://creativecommons.org/publicdomain/zero/1.0/). No third-party material
or reader-engine/API mocks are included. The PDF uses standard Helvetica PDF
text operators so its text is selectable and extractable.

Regenerate with `python3 fixtures/generate.py` from `e2e/`.
